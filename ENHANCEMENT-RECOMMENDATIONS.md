**What to Add:**

- "My Projects" page showing all saved drafts
- Auto-save every 30 seconds
- Resume from where they left off

**Implementation:**
```sql
-- New table
CREATE TABLE projects (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  product_type TEXT, -- 'formatter', 'audiobook', etc.

  data JSONB, -- Store all form data
  created_at TIMESTAMPTZ,
  updated_at TIMESTAMPTZ
);
```

**UX Impact:** Users 3x more likely to complete projects when they can save progress
**Revenue Impact:** Higher completion rate = more usage = more upgrades
