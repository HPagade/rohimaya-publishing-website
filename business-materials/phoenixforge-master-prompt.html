  • File Storage: AWS S3 (Bucket: phoenixforge-files)
  • Authentication: NextAuth (Google/GitHub OAuth)
  • CI/CD: GitHub Actions (for automated testing and deployment)

Deployment Plan: Vercel & Cloudflare

  • Vercel Connection: The GitHub Actions workflow must connect the repository to Vercel for deployment (Vercel is the production environment).
  • Cloudflare Domain: The final Vercel deployment URL must be connected to the domain managed on Cloudflare (Set CNAME or A records to point to Vercel).
  • Secrets Management: All API keys must be stored as Environment Variables in the Vercel project settings and accessed securely via `process.env`.
  • Database URL: Use the remote PostgreSQL connection string (`DATABASE_URL`).
