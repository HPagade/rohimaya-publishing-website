🔥 PHOENIXFORGE AI: Complete Feature Integration Manual

**Rohimaya Publishing's Back-End Revenue Engine & Deployment Blueprint**

This document specifies every API, code location, and integration required for the 5-tool suite and privacy compliance.

1. 🔑 Infrastructure, Privacy & Authentication (P0/P1)

All application functionality is secured behind **NextAuth.js** and must adhere to data isolation principles (Zero Trust).

Security & Compliance Mandate

Authentication: **NextAuth.js** (Google/GitHub Sign-In). Required for access to all routes under `/app/` or `/dashboard/`.

Privacy: All content must be tied to the **authenticated `user_id`** (Zero Trust). Dedicated API logic must be implemented for **GDPR/CCPA** deletion requests.

Code Integration Steps (YOU/Copilot)

A. Auth Implementation: Implement NextAuth.js setup (P0) to protect all routes.

Target File: src/pages/api/auth/[...nextauth].ts

B. Database Schema: Add `User` and `Subscription` models to Prisma, linked to `NextAuth.js`.

Target File: prisma/schema.prisma

2. 💰 Revenue Engine Proxies (Stripe & Audiobook)

These temporary API routes secure income and route complex tasks to external, specialized workers (n8n & Python).

A. Stripe Webhook Proxy (P2 - Revenue Capture)

Goal: Securely receive Stripe events (P2) and forward the validated data to the temporary n8n service for database updates.

API Used: Stripe SDK

External Target: N8N_STRIPE_WEBHOOK_URL

Code Integration Steps (YOU/Copilot)

Implement API to validate Stripe signature and POST data to the n8n endpoint. Target File: src/pages/api/proxy/stripe-webhook.ts

B. PhoenixForge Voice Proxy (P3 - Audiobook Generation)

This links the frontend UI to your husband's complex Python script, which handles chunking and ACX compliance.

Goal: Accept user's manuscript text and trigger the external audio job.

External Target: PYTHON_COMPUTE_URL (Husband's secure endpoint)

Data Flow: Next.js -> Sends text/Voice ID -> Python Worker -> Saves MP3 to S3.

Code Integration Steps (YOU/Copilot)

Implement API that accepts the request and securely POSTs the job payload to the Python endpoint. Target File: src/pages/api/audio/generate.ts
